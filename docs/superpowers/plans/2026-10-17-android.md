# Android-Version – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die App läuft mit vollem Funktionsumfang im Querformat auf Android-Smartphones und -Tablets und wird als signierte APK mit jedem Release ausgeliefert.

**Architecture:** Zuerst wird die Plattformschicht neutral gemacht: Export/Import ohne plattformspezifisches SQL, Dateiauswahl hinter einer `FilePicker`-Schnittstelle. Dann bekommt `shared` ein Android-Target mit `androidMain`-Actuals, ein neues Modul `:androidApp` hostet `App(...)` in einer Activity mit ViewModel. Danach Android-Dateiauswahl, Kompakt-Layout für Smartphones (inklusive verkleinerbarem Live-Screen) und der Release-Job.

**Tech Stack:** Kotlin Multiplatform 2.4.20, Compose Multiplatform 1.12.0, Android Gradle Plugin 9.4.1 (`com.android.kotlin.multiplatform.library` + `com.android.application`), SQLDelight 2.1.0 (`android-driver`), androidx.activity-compose 1.13.0, ktor-network 3.4.2.

**Spec:** `docs/superpowers/specs/2026-10-17-android-design.md`

**Abweichung vom Spec (in Task 1 ins Export/Import-Spec übernommen):** Android 8–10 (minSdk 26) hat SQLite < 3.27 ohne `VACUUM INTO`. Der Export legt deshalb eine leere Datei mit dem Schema an und kopiert mit dem bestehenden Merge-Code hinein; die Schema-Version einer Importdatei wird aus dem SQLite-Header gelesen statt per `PRAGMA`. Strecken werden nur mit Strecken abgeglichen, die **vor** dem Import lokal existierten (behebt das Zusammenlegen gleichnamiger Strecken innerhalb einer Datei und macht den Export verlustfrei). Export läuft wie Import unter dem Controller-Lock.

## Global Constraints

- minSdk 26, compileSdk 36, targetSdk 36, JVM-Toolchain 17.
- `applicationId` und `namespace` der App: `de.bavaco.gt7dashboard`; Namespace von `shared`: `de.bavaco.gt7.shared`.
- Querformat fest: `android:screenOrientation="sensorLandscape"`.
- Berechtigungen exakt: `INTERNET`, `ACCESS_NETWORK_STATE` – keine weiteren.
- Kompakt-Schwelle: Breite < 840 dp; der Desktop ist nie kompakt.
- Live-Skalierung: kompakt mindestens Faktor 0.45, sonst wie bisher mindestens 1, höchstens 2.5.
- Plattform-Init ausschließlich in `Gt7Application.onCreate()` (`android:name=".Gt7Application"`).
- Hinweis für später: Ein höheres targetSdk (37+) verlangt voraussichtlich eine Berechtigung für Zugriff aufs lokale Netzwerk – beim Anheben prüfen.
- Export-Endung bleibt `gt7export` (`EXPORT_EXTENSION`), Mitschnitt-Endung `gt7rec`.
- Release-Secrets exakt: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
- UI-Texte bleiben deutsch.
- Am Ende jeder Task grün: `./gradlew :shared:desktopTest :desktopApp:compileKotlin`; ab Task 3 zusätzlich `:shared:testAndroidHostTest`, ab Task 4 `:androidApp:assembleDebug`.

## Review Focus

1. **Android-Dateiauswahl filtert nicht nach Endung** (SAF kennt nur MIME-Typen; Drive liefert evtl. „export (1)“ ohne Endung): Jede Datei muss wählbar sein, erst der Header-Check entscheidet → Tests in Task 1 (`sqliteUserVersion` für Nicht-SQLite und zu kurze Dateien).
2. **Abbrechen der Dateiauswahl:** keine Meldung, kein Fehler, Buttons wieder aktiv → `FilePicker` liefert `null` (Interface-Vertrag, Task 2); geprüft manuell in Task 2 Step 4 (Desktop), Task 5 Step 3 und Task 8 (Android).
3. **Activity wird neu erzeugt** (Dunkelmodus, Split-Screen, Sprache) während einer laufenden Sitzung: Sitzung und Verbindung laufen weiter → ViewModel in Task 4, manueller Check in Task 8.
4. **Schreiben in die gewählte Zieldatei schlägt fehl** (Drive offline, URI entzogen): Fehlermeldung statt Absturz, temporäre Datei wird gelöscht → Test in Task 2 (`saveVia` räumt bei Ausnahme auf).
5. **Zwei Strecken mit gleichem Namen** („Nürburgring“ GP und Nordschleife): Export und Import in eine leere DB behalten beide → Test in Task 1.
6. **Rechner und Smartphone gleichzeitig verbunden:** Verhalten wird in Task 8 gemessen und im README beschrieben; vorab mit zwei Rechnern prüfbar.
